CURRENT BUILD · POWER SYSTEMS

Distribution Transformer Digital Twin

01 / BACK TO WORK ↑
STACK MATLAB · Simulink · Simscape Electrical FOCUS Load behaviour · electrical measurements · condition monitoring STATUS Prototype model / expanding toward data-driven monitoring

The project models a distribution transformer and explores how operating conditions change measurable electrical behaviour. Healthy and overload scenarios are being evaluated as the basis for a future monitoring pipeline.

WHAT I BUILT

Three-phase electrical model, RMS measurement path, power measurement, load-state experiments and a repeatable simulation workflow.

NEXT ENGINEERING STEP

Turn model outputs into structured condition data, connect monitored parameters, then evaluate useful health indicators.

AS MORE MODEL / RESULT SCREENS ARE ADDED, THEY WILL APPEAR HERE.

EDGE SAFETY · ESP32

Incident Detection + Path Tracking

REPO ↗
INPUT MPU6050 acceleration + gyroscope data COMMS I²C · UART · GPS · GSM OUTPUT Local event decision · location SMS · SD logging

The system is designed around edge-side abnormal-motion detection. The ESP32 acquires motion data, decides whether an incident-like event has occurred, then retrieves location information and sends an emergency message through the GSM path.

ENGINEERING CHALLENGES

Reliable I²C reads, UART channel management, GPS sentence parsing, GSM timing, sensor validation and debugging noisy real-world signals.

WHAT I LEARNED

When embedded systems misbehave, inspect the whole chain: power, pins, protocol, timing, data validity, then application logic.
